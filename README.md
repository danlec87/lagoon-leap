# Lagoon Leap

A retro side-scrolling platformer starring Mochi the axolotl. Four worlds, three hidden lotus flowers in each, and an original chiptune soundtrack. Everything (art, music, levels) is generated in code, in one HTML file.

**Play:** https://danlec87.github.io/lagoon-leap/

## Put it on an iPad or iPhone

1. Open the link above in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Open Lagoon Leap from the Home Screen. It runs full screen, saves progress and works offline.

## Controls

- Touch: on-screen arrows and JUMP (hold JUMP to jump higher).
- Keyboard: arrow keys or A/D to move, Space to jump, P to pause, M for sound.
- Game controllers work too.
